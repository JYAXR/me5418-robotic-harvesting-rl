## 运行与产物

在原项目根目录及已有依赖环境中执行：

```bash
python experiments/teammate009_comparison_20261118/run.py
```

需要上述固定提交的相邻工作树以及已完成的准备模型测试记录。`results/protocol.json`保存固定路径与哈希；重跑会读取已完成场景，而不是覆盖历史记录。

- `results/paired_comparison.csv`：每个场景两版成功、损伤、超时和步数。

- `results/known_three_reproduction.json`：三个原场景的复现记录。
- `results/summary.json`：统计、同场景成功集合、重载检查与记录哈希。
- `RESULTS.md`：完成后的中文解释。
