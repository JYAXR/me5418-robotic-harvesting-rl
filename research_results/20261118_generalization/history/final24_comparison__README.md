# 统一实际效果对比

仅新增本目录。冻结现有24个代表模型，对同样的原33场景和新100场景逐一运行；不训练、不改权重、不改原环境，不推送GitHub。
15个DQN/示范辅助DQN与9个纯模仿策略分开汇报。并非把模仿策略冒充新的RL成果。

## 固定流程

1. `python experiments/final_comparison_20261118/run.py --phase freeze`
2. `python -m pytest -q experiments/final_comparison_20261118/test_comparison.py experiments/final_comparison_20261118/test_summary.py tests/test_scene_cache.py`
3. `python experiments/final_comparison_20261118/run.py --phase run --workers 8`

新种子2026111800–2026111899，在冻结前扫描已有记录确认未出现过。不按结果更换场景。
100是本轮预先固定的计算预算，不是课程要求，也没有统计功效保证。
全部策略使用同一原环境、200步上限、原奖励、无执行噪声、无探索、无推理阶段规划器接管。
原有环境重置时的路线可行性认证保持不变，并记录认证与生成尝试。

每个场景由一个工作进程运行所有24个模型，缓存仅复用初始场景、不会共享已变形状态。
每个模型的初始场景与随机数状态指纹必须相同。进程并行不改变各模型的动作或物理计算。
完成一个场景后保存校验标记，可逐场景续跑。异常保留日志并中止，不将异常场景换成容易场景。

模型名单、文件哈希和未纳入的旧尝试见`catalogue.py`和`results/run01/protocol.json`。
最近两组模型沿用此前验证选择：联合6000次、分阶段3000次；不利用新测试重新挑检查点。
早期试验中已经被否决的最终模型也保留为失败对照，不等于推荐部署。

## 解读边界

统一考题使最终效果可比，但历史训练数据量、训练预算和初始化不同，不能把跨组差异全归因于某一个参数。
只在原本匹配的学习率、奖励/恢复、四组坐标与惩罚、模仿消融内部讨论对应变化。
相同测试场景上的多次训练重复不等于多个独立测试集。多数方法只有一个训练初始化。
这里衡量相同生成器的布局泛化，不代表新物理机制、执行噪声、真实树枝或无限枝条数量。

成功率按固定100个场景为分母；损伤、超时分别列出。成功场景的平均步数不能直接跨模型证明速度更快，
因为成功的场景集合可能不同；另提供共同成功场景上的成对步数/距离对比。
