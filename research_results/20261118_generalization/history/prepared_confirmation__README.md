# 准备模型：第二批100个陌生场景复测

目的：确认之前旧场景33/33、新场景25/100的同一个准备模型，在另外一批陌生布局上的表现。不训练、不调参、不选择其他检查点。

## 固定条件

- 模型：`experiments/retention_rebuild_20261118/results/run01/preparation/prepared.pt`。
- SHA-256：`1e37ec748d5244acbc394f5d6cf86068583eb18d242dfbc203c3c418021dd94f`。
- 新场景种子：2026112000–2026112099，共100个。
- 上一批100个种子：2026111800–2026111899，两个集合不重合。
- 执行前搜索项目已有文本记录，确认新种子范围没有出现；随后冻结协议、模型和源代码哈希。
- 环境沿用模型保存的配置：200步上限、执行噪声为0、原奖励和损伤判定不变。
- 每个请求种子都计入分母；损伤、超时和运行报错不得排除或换题。
- 保留初始场景、逐步动作、奖励、位置、接触、变形、终止信息。
- 完成后重载模型，针对出现的每种终局各重复一个场景，核验逐步轨迹一致。

这属于同一种场景生成规则下的新布局测试，不是新物理模型、噪声条件或真实机器人的测试。100是实际测试预算，不是课程要求。该模型此前已根据旧结果受到关注，因此本轮是新场景确认，不代表训练随机种子之间的稳定性。

## 运行

在项目根目录及原有依赖环境下执行：

```bash
python experiments/prepared_confirmation_20261118/run.py
```

脚本只向本目录写入结果。已完成场景会读取已存记录；需要真正的再次独立复测时，应建立新协议及目录，不删除或覆盖本次历史记录。

## 文件

- `run.py`：新增的独立测试脚本；复用之前已检查的冻结评估与模型加载逻辑。
- `results/protocol.json`：运行前冻结的模型、种子、配置与代码哈希。
- `results/episodes/`：全部100个场景的完整记录。
- `results/per_episode.csv`：逐场景简表。
- `results/summary.json`：统计、95% Wilson区间、重载检查及文件哈希。
- `results/reload_checks/`：独立重载后的重复轨迹。
- `RESULTS.md`：中文结果解读，运行完成后写入。

原模型、核心代码、环境配置及旧实验不变；没有推送GitHub。
