# Code provenance and AI assistance

The implementation and released compact checkpoint come from the group
repository snapshot
[`e532751`](https://github.com/JYAXR/me5418-robotic-harvesting-rl/tree/e532751939fc5e6745700f426b79cdf6f7ed5f9c).
The original planner-depth archive comes from group commit
[`58c30f9`](https://github.com/JYAXR/me5418-robotic-harvesting-rl/commit/58c30f92a2f34a5bbeaa9172d45df968965d9ca7).
This bundle uses the English planner-depth report generator and keeps the
original trajectory data, tables and English results.
The dependencies and their versions are listed in `environment.yml`.

Codex assisted with evaluation and verification scripts, the waypoint and
noise comparisons, the TD ablation, the training reproduction workflow,
result analysis, documentation, and local packaging. This record describes
the assistance observed in the final code and experiment work. Each team
member's own declaration should also cover their earlier work, any other
AI assistance they used, and any external code used directly or adapted.
